## Launch with the recorded settings

Set the game, configuration, data and cache paths to files and folders on your PC. Use a separate launch profile under `LOCALAPPDATA` to avoid settings saved by another run. Set `VICTORY_STREAMLINE_DIR` to the folder containing the installed NVIDIA Streamline DLLs.

```powershell
cargo build --locked --release -p victory --features diagnostics
$game = 'D:\Games\MyDump\game_scarlett_master.exe'
$env:LOCALAPPDATA = 'D:\VIctory\best-one-yet\localappdata'
$env:VICTORY_DATA_DIR = 'D:\VIctory\best-one-yet\data'
$env:VICTORY_CACHE_DIR = 'D:\VIctory\best-one-yet\cache'
$env:VICTORY_CONFIG = 'D:\VIctory\best-one-yet\victory.toml'
$env:VICTORY_STREAMLINE_DIR = 'D:\VIctory\nvidia-sdk\Streamline\bin\x64'
$env:VICTORY_LOG = 'info,victory_gpu::shader_cache=debug'

$settings = [ordered]@{
    VICTORY_DISPLAY_MODE = '1920x1080'
    VICTORY_FULLSCREEN = '1'
    VICTORY_MOUSE_CAPTURE = '1'
    VICTORY_FPS_LINE = '0'
    VICTORY_PRESENT_TIMING = '1'
    VICTORY_BVH_BUILDER = '1'
    VICTORY_TEXTURE_BACK = '256x256f41,256x256f16,64x64f16,128x128f36'
    VICTORY_CARD_STEPS = '1'
    VICTORY_ORDERED_FOOTPRINT_FILLS = '1'
    VICTORY_FRAMEGEN_X = '0'
    VICTORY_TEXTURE_ROOM_PERCENT = '80'
    VICTORY_STORY_CLOCK = '1'
    VICTORY_WATER_LIGHT = '1'
    VICTORY_AUTO_VEHICLE = '1'
    VICTORY_PROMPTS = 'keys'
}
$playArgs = @('play', $game, '--series-s', '--res', '1080', '--dlss', 'quality', '--no-framegen-ready')
foreach ($entry in $settings.GetEnumerator()) {
    $playArgs += @('--set', ($entry.Key + '=' + $entry.Value))
}
& .\target\release\victory.exe @playArgs
```

The session used this `victory.toml`.

```toml
[controls]
enabled = true
mouse_capture = true
start_in_vehicle = false
keys_by_position = false
```
